# Raspberry Pi IO Allocation
## I2C Bus - Pressure sensor, Witty Pi (HAT)
* GPIO 2, pin 3 - I2C SDA
* GPIO 3, pin 5 - I2C SCL

## UART - Ultrasonic sensor
* GPIO 14, pin 8 - UART TX
* GPIO 15, pin 10 - UART RX

## Non Reserved - Power control
* GPIO 17, pin 11 - Digital Out

## USB Devices
* USB 1 - Camera
* USB 2 - External WiFi Adapter

Note: HATs use full 40-pin GPIO Header rather than individual pin connections
